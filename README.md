# 福大失物招领（移动端 Web MVP）

福州大学软件工程结对作业第二次——「校园失物招领」纯前端实现。
聚焦核心流程：**启动 → 发布信息 → 浏览/搜索 → 查看详情 → 联系发布者 → 更新状态 → 个人中心管理**。

## 功能简介

- **启动页**：红色基调欢迎页，自动进入首页，也可点击「进入应用」手动进入。
- **首页**：卡片式失物招领列表；支持关键词搜索（匹配物品名称、描述、地点、类别）；支持「全部 / 寻物 / 招领」类型筛选与按类别筛选；无结果时显示空状态并引导发布。
- **发布页**：可发布「寻物（我丢了东西）」和「招领（我捡到东西）」；字段包含类型、物品名称、类别、地点、时间、描述、联系方式、发布者昵称；完整表单校验；发布成功后跳转**发布成功页**。
- **发布成功页**：展示发布成功动画与信息摘要，提供「返回首页」和「查看详情」按钮。
- **详情页**：根据 id 展示物品全部信息；状态标签区分「寻物中 / 已找到」「招领中 / 已归还」；一键复制联系方式；可**收藏**；发布者可将信息标记为已找到 / 已归还。
- **个人中心**：展示头像、昵称、数据统计（发布 / 已找回 / 收藏），提供「我的发布、我的收藏、消息通知、设置」快捷入口。
- **我的发布**：本机发布的信息管理（查看、标记完成、删除）。
- **我的收藏**：收藏的信息列表，可查看详情或取消收藏。
- **消息通知**：匹配提醒、浏览动态、归还提醒、系统通知，支持单条/全部已读。
- **设置**：修改昵称与头像、清除全部数据并恢复示例。
- **底部导航**：首页、发布（中间凸起按钮）、我的，三个页面一键切换。
- **示例数据**：首次打开自动写入 6 条示例数据（含寻物/招领、进行中/已完成）、1 条默认收藏、默认个人资料。

## 使用说明

### 方式一：直接双击运行（推荐）

1. 下载或克隆本项目，保持目录结构不变；
2. 直接双击 **`splash.html`**（启动页），选择用 **Google Chrome（谷歌浏览器）** 打开；
3. 启动页会在约 2.5 秒后自动进入首页，也可点击「进入应用」手动进入；
4. 首次打开会自动生成示例数据，随后即可体验全部功能。

> 也可双击 `index.html` 直接进入首页（跳过启动页）。
> 本项目为纯静态页面（原生 HTML + CSS + JavaScript），不依赖任何框架、打包工具或外部 CDN，断网也能正常使用。

### 方式二：本地服务器运行（可选）

```bash
cd lost-found
python3 -m http.server 8000
```

然后在谷歌浏览器打开 `http://localhost:8000/splash.html`。

### 想恢复为初始示例数据？

进入「个人中心 → 设置 → 清除全部数据并恢复示例」，或在浏览器开发者工具 Console 执行 `localStorage.clear()` 后刷新页面。

## 数据存储说明

- 所有数据保存在浏览器的 **localStorage** 中，**不会上传到任何服务器**。
- 主要存储 key：

| key | 内容 |
|---|---|
| `lost_found_items_v1` | 全部失物招领信息 |
| `lost_found_mine_ids_v1` | 本机发布的信息 id 列表 |
| `lost_found_favorites_v1` | 收藏的信息 id 列表 |
| `lost_found_profile_v1` | 个人资料（昵称、头像） |
| `lost_found_read_msgs_v1` | 已读消息 id 列表 |

- 每条信息的数据模型：

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | string | 信息唯一标识 |
| `type` | string | `lost`（寻物）/ `found`（招领） |
| `title` | string | 物品名称 |
| `category` | string | 类别（校园卡、钥匙、雨伞、耳机、水杯、书籍、其他） |
| `location` | string | 丢失 / 拾取地点 |
| `time` | string | 丢失 / 拾取时间 |
| `description` | string | 物品描述 |
| `contact` | string | 联系方式 |
| `publisher` | string | 发布者昵称 |
| `status` | string | `active`（进行中）/ `done`（已完成） |
| `createdAt` | number | 发布时间戳（毫秒） |

- `status` 为 `done` 时，结合 `type` 展示：寻物显示「已找到」，招领显示「已归还」。
