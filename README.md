# 福大失物招领（移动端 Web MVP）

福州大学软件工程结对作业第二次——「校园失物招领」纯前端实现。
聚焦核心流程：**发布信息 → 浏览/搜索 → 查看详情 → 联系发布者 → 更新状态**。

## 功能简介

- **首页**：卡片式失物招领列表；支持关键词搜索（匹配物品名称、描述、地点、类别）；支持「全部 / 寻物 / 招领」类型筛选与按类别筛选；无结果时显示空状态并引导发布。
- **发布页**：可发布「寻物（我丢了东西）」和「招领（我捡到东西）」；字段包含类型、物品名称、类别、地点、时间、描述、联系方式、发布者昵称；完整表单校验（必填、长度、时间不能晚于当前），发布成功后保存并跳转详情页。
- **详情页**：根据 id 展示物品全部信息；状态标签区分「寻物中 / 已找到」「招领中 / 已归还」；一键复制联系方式；发布者可将信息标记为已找到 / 已归还。
- **我的发布**：展示本机发布的所有信息及统计（发布总数 / 进行中 / 已完成）；可查看详情、标记完成、删除（删除有二次确认）。
- **底部导航**：首页、发布（中间凸起按钮）、我的，三个页面一键切换。
- **示例数据**：首次打开自动写入 6 条示例数据（含寻物/招领、进行中/已完成），方便直接演示。

## 使用说明

### 方式一：直接双击运行（推荐，作业要求方式）

1. 下载或克隆本项目，保持上面的目录结构不变；
2. 直接双击 `index.html`，选择用 **Google Chrome（谷歌浏览器）** 打开；
3. 首次打开会自动生成 6 条示例数据，随后即可体验浏览、搜索、发布、标记完成等全部功能。

> 本项目为纯静态页面（原生 HTML + CSS + JavaScript），不依赖 Vue/React、Webpack、npm，
> 也没有任何外部 CDN、外链图片或外部字体，图标全部使用 emoji，断网也能正常使用。

### 方式二：本地服务器运行（可选）

若希望通过 `http://` 访问，可在项目目录下启动任意静态服务器，例如：

```bash
# Python 3
python3 -m http.server 8000
```

然后在谷歌浏览器打开 `http://localhost:8000/index.html`。

### 想恢复为初始示例数据？

在浏览器开发者工具（F12）→ Application → Local Storage 中，删除以下两个键后刷新页面即可：

- `lost_found_items_v1`：全部失物招领信息
- `lost_found_mine_ids_v1`：本机发布的信息 id 列表

## 数据存储说明

- 所有数据保存在浏览器的 **localStorage** 中，**不会上传到任何服务器**。
- `lost_found_items_v1`：JSON 数组，每条信息的数据模型为：

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | string | 信息唯一标识 |
| `type` | string | 类型：`lost`（寻物）/ `found`（招领） |
| `title` | string | 物品名称 |
| `category` | string | 类别（校园卡、钥匙、雨伞、耳机、水杯、书籍、其他） |
| `location` | string | 丢失 / 拾取地点 |
| `time` | string | 丢失 / 拾取时间 |
| `description` | string | 物品描述 |
| `contact` | string | 联系方式（QQ / 微信 / 手机号） |
| `publisher` | string | 发布者昵称 |
| `status` | string | 状态：`active`（进行中）/ `done`（已完成） |
| `createdAt` | number | 发布时间戳（毫秒） |

- `status` 为 `done` 时，结合 `type` 展示：寻物显示「已找到」，招领显示「已归还」。
- `lost_found_mine_ids_v1`：JSON 数组，记录本浏览器发布过的信息 id，用于「我的发布」页面；清除浏览器数据会同时清空上述内容。
